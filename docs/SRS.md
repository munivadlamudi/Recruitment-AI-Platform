# Recruitment AI Platform

## Software Requirements Specification (SRS) v1.0

### Vision
Develop an AI-powered recruitment assistant that automates resume screening, candidate scoring, panel recommendation, and recruiter reporting.

## Sprint 1
- Project setup
- Resume parser
- Job Description parser
- Domain models
- Logging and configuration

## High-Level Architecture
User -> API/UI -> Orchestrator -> Resume Agent -> JD Agent -> Scoring Service -> Panel Matching Service -> Report Service

This is the initial SRS. It will evolve throughout development.
